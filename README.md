# Werk

**Compose rhythm through musical conversation.**

Werk is a REAPER instrument built around three rhythmic musicians:

- **Slot A — Primary Groove**
- **Slot B — Counter-Rhythm**
- **Slot C — Structural Punctuation**

Each slot can host any Werk engine. The engine provides character; the slot provides purpose. PulseWerk in Slot A should not behave like PulseWerk in Slot B. MetalWerk in Slot B should challenge the groove differently from MetalWerk in Slot A.

Werk begins as a consolidation of the existing Werk drum engines and grows from a jam tool into a compositional instrument that can work alongside [HIT](https://github.com/gmcnicol/hit).

## Current Victory

**Victory I — Werk Exists**

One JSFX instrument hosts three selectable engines in the three fixed roles and produces a coherent playable result.

See [docs/CURRENT_VICTORY.md](docs/CURRENT_VICTORY.md).

## Product Commitments

- sixteen semantic drum pads;
- REAPER MIDI note-name map support;
- Form as a first-class view;
- engines that listen and respond rather than merely stack notes;
- immediate-mode `gfx`, recalculated every frame;
- no retained widget tree;
- no speculative UI framework;
- slick, bespoke presentation that does not look constrained by JSFX;
- accessible interaction for beginners and differently abled producers;
- MIT licensed.
